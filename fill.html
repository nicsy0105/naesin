평가 채우기 버튼

맥가이7 출석입력 화면에서 이 버튼을 누르면, 앱에 제출된 그날 점수로 학생마다 평가 칸의 빈 점수를 채워요.
저장과 문자 발송은 하지 않아요. 확인한 뒤 선생님이 직접 누르시면 돼요.

1. 설치 (처음 한 번)

  1. 즐겨찾기 막대가 안 보이면 Ctrl+Shift+B를 눌러요.
  2. 아래 검은 버튼을 마우스로 끌어서 즐겨찾기 막대에 놓아요. (누르는 게 아니라 끌어다 놓기)
평가 채우기
학원 PC, 노트북처럼 쓰시는 컴퓨터마다 한 번씩 설치해요. 버튼 안에는 학생 정보가 없어요.

2. 쓰는 법 (매번)

  1. 맥가이7 클리닉수업관리 → 출석입력에서 날짜를 고르고 [검색]
  2. 평가 칸에 그날 틀(예: - 총 / 30문항, - 품사 : / 30)이 들어 있는지 확인
  3. 즐겨찾기 막대의 [평가 채우기] → 내신 클리닉 선생님 비밀번호 입력 (6시간 동안은 다시 안 물어봐요)
  4. 오른쪽 위 결과 창과 평가 칸을 확인하고 [저장]
  5. 클리닉수업문자에서 평소처럼 [문자보내기]
· 채우는 줄: 총 / N문항, 그리고 문항 탭의 단원 이름과 같은 줄(예: 품사). 틀의 문항 수와 앱 기록의 문항 수가 같을 때만 채워요.
· 자습서·평가문제집, 앱에 없는 테스트 줄, 이미 숫자가 있는 줄은 건드리지 않아요.
· 학생은 출석입력의 이름 + 학교로 앱 학생 탭과 맞춰요. 두 곳의 이름·학교가 같아야 해요.
