# 내신 클리닉

학생이 확인 테스트 답(OMR)을 내고, 선생님이 오늘 결과와 주차별 누적 리포트를 보고, 학부모가 자기 아이 리포트를 보는 웹앱입니다.

> 이 저장소는 공개입니다. **실제 학생 이름·점수는 절대 올리지 않습니다.**
> 실제 자료는 모두 선생님의 구글 시트에만 있습니다. 여기 있는 `가상학생`, `샘플고`는 테스트용 가짜 자료입니다.

## 파일

| 파일 | 하는 일 | 어디에 두나 |
|---|---|---|

| `teacher.html` | 선생님 화면 (오늘 결과) | 이 저장소 (GitHub Pages) |
| `report.html` | 선생님 화면 (누적 리포트, v1.1.0) | 이 저장소 (GitHub Pages) |
| `parent.html` | 학부모 화면 (자기 아이 리포트, v1.5.0) | 이 저장소 (GitHub Pages) |
| `fill.html`, `fill.js` | 맥가이7 출석입력 화면의 '평가 채우기' 즐겨찾기 버튼 (v1.3.0) | 이 저장소 (GitHub Pages) |
| `config.js` | 서버 주소(웹 앱 URL) 한 줄 | 이 저장소 |

| `tools/` | 가짜 자료로 화면을 띄워 확인·캡처하는 도구 | 기록용 |

## 정해 둔 규칙

- 채점: 고른 선지가 정답과 **완전히 같아야** 맞음(부분 점수 없음). 비운 문항은 틀림. 배점 합계를 100점 만점으로 환산.
- 학생 비밀번호: 처음 0000 → 첫 로그인 때 반드시 바꿈. 시트에는 해시만 저장. 5번 틀리면 15분 잠금.
- 결과: (v1.2.0) 세트 탭 `결과공개` 칸이 Y인 세트만 학생에게 점수와 틀린 문항 **번호** 공개(정답은 안 보여 줌). 비어 있으면 학생에게는 자기가 칠한 답만 보이고 종이 답안지로 직접 채점. 선생님 화면에는 항상 점수가 보임. 같은 세트는 한 번만 제출.
- 문항 태그: 문항 탭의 `단원`, `세부항목` 칸.
- (v1.1.0) 주차: 세트 탭의 `주차` 칸(숫자). 비어 있으면 주차별 점수에서 빠짐.
- (v1.1.0) 주차 점수 = 그 주차 세트 점수의 평균. 평균 = 주차 점수들의 평균.
- (v1.1.0) 약한 세부항목 = 2문항 이상 풀고 정답률 80% 미만인 것 중 낮은 순 3개.
- (v1.1.0) 학생은 '내 성적 추이'에서 자기 기록만 봄. 선생님 누적 리포트의 반 평균은 집계만.
- (v1.2.0) 학생 '내 성적 추이'에는 결과를 공개한 세트만 들어감. 선생님 누적 리포트에는 모든 세트.
- (v1.3.0) 평가 채우기: 맥가이7 출석입력의 평가 칸에서 `- 총 / N문항`, `- 단원 : / N` 줄의 빈 점수만 채움(문항 수가 앱 기록과 같을 때만). 이미 숫자가 있는 줄·다른 줄은 그대로, 저장·발송은 선생님이 직접. 학생은 이름+학교로 맞춤.
- (v1.4.0) 세트 탭 `종류` 칸: 비우면 내신, '모의'가 들어가면 모의평가(학교별 기출 모의평가). 모의평가는 `주차` 칸에 회차를 적음. 학생 홈·성적 추이와 선생님 누적 리포트에서 따로 보임. 세부항목 집계는 둘 다 합침.
- (v1.4.0) 세트 탭 `학년` 칸: 비우면 그 학교 전체, 숫자를 쓰면 그 학년 학생에게만 보임.
- (v1.5.0) 학부모: 학교+자녀 이름+학부모 비밀번호로 로그인. 처음 비밀번호는 선생님이 시트 메뉴 '선택한 학생 학부모 초기 비밀번호 만들기'로 만든 6자리 번호(시트에는 해시만, 번호는 만들 때 창에 한 번만 보임). 첫 로그인 때 6자 이상으로 바꿈. 5번 틀리면 15분 잠금.
- (v1.5.0) 학부모는 자기 아이 것만 봄: 최근 테스트 결과, 주차별(내신)·회차별(모의평가) 점수, 약한 세부항목. 학생에게 비공개인 세트도 보임. 다른 학생은 같은 학교 반 평균으로만, 그것도 3명 이상 냈을 때만(2명이면 평균으로 다른 아이 점수를 알 수 있어서).
- (v1.5.0) 평가 채우기: 학부모 비밀번호를 만든 학생은 평가 칸 끝에 '■ 성적 리포트' 링크 줄을 한 번만 붙임.
- (v1.6.0) 서답형 합산: 세트 탭 `서답형배점` 칸에 서답형 문항별 만점을 쉼표로(예: `4, 4, 4, 4, 4`). 비우면 예전처럼 객관식만. 채우면 객관식 = 맞힌 배점/배점 합계 × (100 − 서답형 만점), 서답형은 [서답형] 탭에 선생님이 문항별로 적음(메뉴 '선택한 세트 서답형 입력표 만들기'가 제출한 학생 줄과 객관식 점수를 만듦). 서답형 칸을 다 채운 학생만 합계가 나오고, 그 전에는 '채점 전'으로 추세·반 평균에서 빠짐. 만점보다 큰 값은 '확인 필요'.
- (v1.6.0) 서답형배점이 있는 세트는 결과공개 칸과 상관없이 학생에게 점수 비공개(제출 완료 + 내가 칠한 답만).
- (v1.6.0) 평가 채우기: `- 객관식 : / 80`, `- 서답형 : / 20`, `- 합계 : / 100` 줄(만점이 같을 때만, 서답형·합계는 채점 뒤에만).

## 테스트 (고친 뒤 배포 전에 전부 통과해야 함)

```
node test/run-tests.js      # 서버 테스트 (Node만 있으면 됨)
node tools/shots.js         # 화면 테스트 + 캡처 (Playwright 필요)
node tools/shots-fill.js    # 평가 채우기 버튼 테스트 (맥가이7 출석입력을 흉내 낸 가짜 페이지)
```
